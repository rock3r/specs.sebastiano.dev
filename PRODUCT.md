# Product

## Register

brand

## Users

Sebastiano first, with collaborators and curious readers as the secondary audience. They arrive looking for a specific design document or to browse the latest thinking across active projects.

## Product Purpose

Specs is a small public index for design documents published as Cloudflare Worker sites. It makes scattered project notes discoverable, keeps each project together, and puts the newest work first.

## Brand Personality

Personal, direct, and playful. It should feel like Sebastiano's existing home page: confident enough to be useful, informal enough to feel authored, and visually memorable without becoming a product dashboard.

## Anti-references

Do not make this look like a SaaS dashboard, a generic documentation portal, a card-heavy portfolio, or a separate glossy marketing microsite for every project. Avoid decorative gradients, anonymous stock imagery, and explanatory UI copy that tells people how to use the page.

## Design Principles

- Keep the archive legible at a glance: project grouping and date ordering do the organizing work.
- Let the personal site identity carry the surface: recognizable color, type, and monogram treatment.
- Prefer a short authored description over metadata clutter.
- Make every entry a direct path to the source document.
- Keep publishing mechanical so the index stays current as new Workers appear.

## Accessibility & Inclusion

Use semantic headings and lists, visible keyboard focus, link text that makes sense out of context, strong text contrast, responsive layouts, and reduced-motion behavior. The catalog must remain usable without hover, color perception, or JavaScript timing assumptions.
